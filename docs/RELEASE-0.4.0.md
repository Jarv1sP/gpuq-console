# 0.4.0 · 更清晰的数据与训练流程

本页描述版本中的功能。代码合入不等于实例已经升级；私网传输和云盘还需要管理员完成各自的配置与真实验收。

## 日常使用

- **数据集只有一个入口**：查看固定版本、已就绪的位置和所选机器容量；添加数据时再展开目录上传、链接导入或文件整理。
- **先准备数据，再占显卡**：选择服务器和项目后，可把有可用来源的数据准备好再训练。准备阶段不占 GPU 额度，完成后重新核验授权、数据与项目版本。
- **传输可追踪**：上传、固定版本下载和服务器间复制有独立记录。服务器间复制在后台继续；本机上传仍需要电脑在线。取消、恢复和状态未知会明确区分，不偷偷重复启动。
- **任务更好辨认**：同机获授权成员可查看任务名与提交者填写的说明，原始命令、日志和个人结果不因此公开。
- **指南按工作流程分章**：从注册、项目开发到训练、数据和结果，一个入口即可查阅。帖子与聊天仍保留，不再增加重复板块。
- **登录可以跨重启保留**：网页和 CLI 不再因门户重启而丢失登录；退出、改密、账号停用或角色变更仍会撤销相应会话。由旧版本升级时需重新登录一次，此后按 30 天未活动过期。
- **STARGATE 工作空间**：墨黑、瓷白与银灰的视觉层次，原创字标，以及与状态和操作相连的轻量动效；支持手机、键盘操作与减少动态效果设置。仅网页展示名称改变，仓库、域名与 `gpuctl` 保持兼容；本项目不隶属于 SpaceX、Tesla 或 Elon Musk。

## 数据走哪里

个人电脑的上传仍通过门户 HTTPS；启用节点间私网通道后，已有 READY 数据可按需复制到另一台获授权服务器，文件字节不经过 VPS。默认不开监听、不猜测节点地址，也不会复制所有数据或迁移旧磁盘。

项目代码与环境仍须在目标服务器准备和发布；跨机复制数据不是自动搬运整个开发环境。结果与数据副本不是备份，请保留原始文件。

## 管理员注意

- 门户、执行桥与完整节点 runtime 需使用配套版本；已有数据库、机器清单、授权、数据路径和训练保持兼容。
- 新数据准备复用持久传输服务；固定内容版本、账号隔离、源租约、目标校验和最终 READY 缺一不可。
- 远程传输不占用全局操作队列。网络未知不会当作成功停止，取消或撤权会阻止迟到的派发。
- 检查数据盘确实挂载且可写，挂载丢失时拒绝写回系统盘。
- CloudDrive2 为单实例可选后台，默认关闭。只有完成账号授权、能力探测与真实分享下载后才能对用户启用；不分发管理员网盘令牌。

具体操作见[使用指南](USER_GUIDE.md)、[数据集手册](DATASETS.md)和[传输手册](TRANSFERS.md)。
