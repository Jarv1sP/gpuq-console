# 大文件链接导入

默认原生 Aliyun 后台由管理员在「数据集 → 云盘连接」扫码连接一次阿里云盘。成员把压缩包放入自己的云盘，创建分享链接，在「链接导入」选择文件和服务器即可。也支持可直接下载的 HTTPS 文件链接。可选 CD2 后台为独立、默认关闭的试点适配器，授权与能力验收规则见 [CloudDrive 专用接入](CLOUDDRIVE.md)，不套用原生扫码流程。

文件由目标训练服务器下载到该用户的个人 `/data2`。VPS 只解析链接、传送短期下载地址和查询进度，不中转文件内容。成员不能浏览管理员的网盘，也拿不到账号令牌；不能借导入访问其他成员的数据。是否获得会员下载速度由云盘服务端决定，不能保证所有分享都不限速。

## 使用边界

- 当前选择分享根目录中的文件，不递归搬运文件夹。几十 GB 的数据建议先压缩，再分享。
- 下载前关闭这台服务器上的个人数据终端。下载期间个人数据目录锁定，项目终端与训练不受影响。
- 完成后在数据终端自行检查、解压；不会自动执行文件、解压或发布数据集。
- 目标文件不覆盖已有文件。发布后训练读取固定数据版本，导入不改变已有作业。
- 取消会停止下载并保留临时文件。点击「继续」尝试恢复；仅在同一资源的强 ETag 或预期校验值证明文件未变时续传。无法确认、文件已变或服务器不支持 Range 时，会明确停止；请清理该导入，再新建下载，不会自动拼接或重下。
- 不再需要的导入可「清理」。系统确认后台下载已停止后才删除记录和隐藏临时文件；已下载到个人 `/data2` 的文件不会被删除。
- 阿里云盘短链过期时，继续操作会重新解析分享。普通 HTTPS 短链需要用户提供新的下载地址。
- 节点默认单文件上限 1 TiB、个人可变数据与导入暂存合计上限 2 TiB，沿用 `datasets.uploads.maxUploadBytes/maxUserBytes` 设置；如采用共享容量，可将 `maxUserBytes` 显式设为 `0` 关闭个人字节份额，条目和目录深度检查仍有效。下载前始终检查容量与全节点预留空间。它不是覆盖所有已发布副本、任意终端写入的文件系统硬配额。导入不占 GPU。VPS 每账号保存最多 1000 条导入源记录，节点列表显示最近 50 条，可清理不再需要的记录。

## 管理员须知

扫码授权可能授予整个云盘账号的访问能力，**不是云盘侧的文件夹级授权**。平台仅开放分享解析接口，不提供列出账号目录、转存、删除账号文件等接口。建议运营方使用专用云盘账号；不要复用媒体服务或其他服务的令牌。

刷新令牌和源链接用 AES-256-GCM 加密存入门户 SQLite，使用部署目录现有的 `.invite-key` 密钥。数据库与该密钥必须一并私密备份；这不能抵御已控制 VPS/root 或同时取得数据库和密钥的人。节点只收到短期下载链接，不保存长期云盘令牌。管理员点「断开」后不再解析新链接；已签发的短期链接可能在有效期内继续下载，必要时再取消节点任务。

节点只接受 HTTPS 443 公网地址，逐跳检查 DNS、固定连接地址并核验 TLS；拒绝回环、私网、链路本地与元数据地址。导入不继承用户自定义代理，也不修改服务器出口路由。

HTTPS 来源需提供已知 `Content-Length`，不接任意 Cookie、Authorization 或自定义请求头。原生阿里云盘使用固定公开 Referer；CD2 只允许服务端签发的有限 UA、官方根地址 Referer/Origin，并在门户和节点分别验证，成员不能自行传入这些头。普通链接如要跨域名或文件路径刷新后续传，应在新建导入时提供 SHA-256；只更换签名查询参数可按同一资源的强 ETag 验证。源码与运行日志、命令行、公开回执均不打印源链接；节点仅在当前用户不可从个人终端访问的私有导入元数据中保存下载所需链接，完成或清理后删除。CD2 账号凭据与内部文件回执绝不传给节点或成员。

CD2 后台的 `cloud.info` 明确标记 `backend:clouddrive`、`managedExternally:true` 及配置状态，不主动探测服务。管理员 `cloud.auth.disconnect {}` 会持久禁用 CD2，重启不会自行恢复，也不删除旧原生 Aliyun 凭据；`cloud.auth.reconnect {}` 只重新启用私有配置中已启用且已验收的 CD2，不执行登录或扫码。后台更换后不能用另一后台续传旧分享回执，普通 HTTPS 导入仍独立可用。详细操作见 [CD2 维护说明](CLOUDDRIVE.md#门户维护操作与持久断开)。

网页分享与扫码接口可能变动；故障时 HTTPS 直链导入与原有上传仍可独立使用。上线验收必须分别记录：模拟安全测试、节点实际下载、真实扫码与分享下载，不能互相替代。
