# 0.4.2 — 后台数据恢复的挂载身份修复

- 修复在 SSH 进程封存原件后，启用了 systemd `PrivateTmp` 的传输服务拒绝读取同一原件的问题。Linux 挂载编号只在各自的挂载命名空间内有效，不能作为跨进程的永久设备标识。
- 保持既有封存回执、授权及其哈希不变；跨进程验证物理设备、根目录 inode、登记及只读内容身份、权限和永久保留标记。每个运行实例仍检查完整实时挂载编号，掉盘、运行期间重挂或换目录继续拒绝。
- 清除用户手册开头混入的一行命令警告，增加回归测试。

本修复不启用自动清理、不迁移数据目录、不改变用户权限或训练配额。普通上传的自动机械盘归档、后台缓存认证及独立备份仍需另行接通和验收；不把恢复底座等同于完整自动流程。

部署时在没有活动传输的窗口更新配套节点运行时，并重启节点传输服务加载新模块；不需要重启 GPUQ 调度器或训练。
