# 协作区

登录后，从左侧“协作区”进入。这里的内容对所有已登录成员可见，包括尚未获得 GPU 额度的成员；不能放入密码、登录令牌或私密数据。退出登录后无法读取。

## 三个入口

| 入口 | 适合的内容 | 谁可以发布 |
|---|---|---|
| 公告 | 维护时间、停机安排、故障和重要通知 | 管理员 |
| 问题反馈 | 操作遇到的问题、复现步骤、处理进展 | 所有成员 |
| 公共交流 | 预计结束时间、排队协调和使用计划 | 所有成员 |

公告只是通知，不会自动停机、取消训练或调整权限。聊天中的使用约定也不会替代调度器和管理员授权。

## 发帖与跟进

1. 在“问题反馈”选择“反馈问题”，写清标题、操作步骤、服务器或任务 ID、现象和错误信息。
2. 打开帖子可以回复、补充进展；作者可修改或删除自己的帖子与回复。
3. 管理员可将反馈标为待处理、处理中、已解决或已关闭。只有公告可以置顶。
4. 管理员可以删除不适宜的内容，但不能改写其他成员的正文。删除帖子时，其回复也会一并删除。

修改和删除会校验你看到的版本。如果其他人已更新，页面会提示刷新后再操作，不会覆盖新内容。分页是实时列表，处理状态或置顶变化后应刷新首页查看最新顺序。

## 公共聊天

最新消息在下方，打开聊天室时每 5 秒读取新消息，每轮最多读取 150 条；较多积压会分轮补齐。近期 50 条约每 30 秒重新核对编辑和删除，旧消息可手动刷新确认。查看历史消息时暂停自动更新，选择“返回最新消息”恢复。聊天最多保留 5,000 条、30 天；它不适合保存长期实验记录。

帖子和回复由服务器持久保存。标题最多 120 字，帖子正文 8,000 字、回复 4,000 字、聊天 2,000 字，同时分别受 UTF-8 字节上限 360、24,000、12,000、6,000 限制；大量表情符号可能先达到字节上限。内容按纯文本显示，不执行 HTML，也不渲染脚本。

每位成员每分钟最多发布 3 篇帖子、10 条回复、20 条聊天消息，合计写操作不超过 60 次。达到限制时请稍后重试，文本仍会保留。全站帖子和回复上限分别为 10,000 和 100,000；达到容量时需要管理员处理。

## 网页任务留言

任务留言页需要后台提供 `task-notes-v1` 能力。此页面不实现或替代后台 API；后台未启用时隐藏入口，原有帖子、评论和聊天保持不变。

启用后，先选“随任务结束删除”或“非任务留言，手动删除”。关联任务可看到自己的任务名、服务器、状态和 UUID；未知状态任务仍可留言。支持刷新、编辑、删除；未确认的发送锁定原内容和保留方式，重试使用同一提交键，并发编辑冲突时保留当前草稿。所有登录成员可读，请勿填写敏感信息。

## 网络中断与草稿

发送结果未确认时，请保留页面并点击同一发送按钮重试；原内容会锁定，服务端用同一个发送标识确认结果，避免重复发布。不要刷新页面、另开编辑器或换账号后再发一份相同内容。删除或过期内容的重试不会重新发布。

普通刷新数据和切换页面不会丢失正在输入的草稿。草稿只暂存在当前页面，不写入浏览器长期存储；重新载入网页、关闭页面或退出账号会清除草稿。若协作服务未启用或不可用，页面会明确提示，并禁用发布功能。
