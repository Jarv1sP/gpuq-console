# STARGATE 界面设计

STARGATE 是一间控制室。顶栏、服务器与项目上下文、总控条保持位置；切换房间时只移动内容。训练、会话、后台数据任务和获授权服务器始终可达，需要处理的事实排在最前。

每页只保留一个主视觉：工作台是当前训练，算力是服务器阵列，数据集是就绪位置矩阵，协作区是置顶公告与最新帖子。其余内容分为可操作列表和默认折叠的详情。每屏一个实心主操作，行操作用安静按钮，破坏性操作先确认代价。

算力阵列按机器的真实物理卡数排列，柱高表示采集到的显存比例；只有节点确认进程属于自己的平台任务时才使用白色填充。监控指标、计算进程证据和调度器状态分别表达，未检测到计算进程不意味着训练能立即启动。页面只展开所选服务器，成员可读同机器任务信息；程序、系统用户和节点任务 ID 仅管理员可见。完整指标和队列默认折叠，刷新保留所选服务器、展开状态及进程滚动位置。手机从阵列进入视口高度的详情，内容在抽屉内滚动；返回阵列恢复焦点。

工作空间使用 Carbon，指南使用 Porcelain。Archivo 300 用于主读数和对象名称，Geist 用于界面，Geist Mono 用于 ID、命令、时刻；汉字使用系统字体。字体以 WOFF2 同源自托管。状态同时以字形、文字和颜色表达：运行绿点、启动虚线环、排队琥珀环、数据蓝色半填、失败红菱形、取消灰方。未知和过期使用静止斜线，不能显示为空闲或零。

总控的数值只取已确认的客户端状态。无对象的分段收起；无自报进度不画进度线，不推算队列位置、结束时间或终端倒计时。管理员专属数据服从原接口权限，普通成员只看到自己的任务及获授权服务器。

桌面房间顺序为工作台、算力总览、数据集、协作区、成员授权；每个房间保留返回位置。手机使用五个标签和向上展开的总控胶囊，工作台不重复显示胶囊。胶囊与主操作在同一行，内容预留底部控制层的真实高度。

批准的动效只有真实状态差异：运行状态 2.4 秒透明度提示；启动虚线环 1.6 秒，取消字形保持静止；轨迹 320/220 毫秒；可信液位 480 毫秒；读数 220 毫秒；抽屉 320 毫秒、退出 220 毫秒；对话框与提示 220 毫秒；终端和总控从总控条揭开 320 毫秒；分段指示 220 毫秒；悬停只改变颜色 140 毫秒。房间内容退出 180 毫秒、进入 280 毫秒，手机标签淡变 200 毫秒，二级页面从右侧推入 350 毫秒并保留 30% 底层视差，提交抽屉从下方进入 380 毫秒。共享对象使用 320 毫秒 FLIP，退出的视觉快照不持有应用 ID，也不截获操作。首次载入只允许 220 毫秒内容淡入。减少动态时使用 150 毫秒原位淡变，减少透明度时导航使用实色。

共享设计令牌和组件在 `dist/starbase.css`，字体声明在 `dist/fonts.css`，应用外壳适配在 `dist/shell.css`。页面模块保留原有 API、权限和 DOM 钩子，样式和结构变化不改变执行协议。
