# STARGATE

STARGATE 是独立开源研究计算工作台。名字、服务器、显卡、任务和数据集使用清楚的普通词汇，不使用虚构的航天术语。

视觉采用深黑 Carbon 工作空间和浅色 Porcelain 指南。横向字标使用 Archivo Expanded SemiBold 轮廓，两处 A 呈 Λ；独立符号为「Λ 门」，由 Λ 与收尖的地平线组成。顶栏只使用字标，浏览器和主屏幕图标使用符号。字标由 CSS mask 描绘，保留 STARGATE 的可访问名称。Archivo 的细字重用于大读数；Geist 与 Geist Mono 分别承担界面和数据。字体同源自托管，不请求外部字体服务。

一页一个主视觉，以间距、字级和细线区分层级。四角细框仅围住主视觉；运行轨迹、真实显卡槽、导航玻璃和空态地平线是批准的母题。颜色只表示状态，未知使用静止斜线。禁用渐变装饰、发光、霓虹、扫描线和虚构仪表。
