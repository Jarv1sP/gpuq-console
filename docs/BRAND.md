# STARBASE · 品牌与界面

STARBASE 是独立开源研究计算工作空间。名称向 SpaceX 的 Starbase 基地致意：在一个基地里准备、协作、检验并启动工作。它不是 SpaceX、Tesla 或 Elon Musk 的官方项目，也不表示获得其背书。

产品中的服务器、数据集、训练、传输等名称仍使用直白的中文，不把日常操作改成需要学习的航天术语。命令、仓库、部署服务和既有账号不随网页品牌更名。

## 视觉原则

- **先有秩序，再有装饰。** 墨黑、瓷白和银灰建立层次；状态色只表达状态。主标题、实时摘要和操作区各有明确视觉权重。
- **保留精度。** 细线、留白、数字和对齐承担主要表现，不靠满屏发光、复杂纹理或重复卡片营造氛围。重要说明保持可读字号与对比度。
- **动效有原因。** 转场帮助理解所在位置，进度表达真实工作；不制造虚假数字、常驻成功状态或随机遥测。减少动态效果、键盘、触屏和窄屏与桌面同等重要。
- **品牌不盖过工具。** 原创字标与上升轨迹是识别元素，不复制官方徽标、照片、视频、字体或产品界面；不引入第三方字体追踪和重型动效库。

- [Apple：Mac](https://www.apple.com/mac/) 与 [Tesla：Cybertruck](https://www.tesla.com/cybertruck)：本次用户指定的产品表达参考，不表示获得其视觉素材许可。
- [Apple Human Interface Guidelines：Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：动效应支持理解与反馈，避免无目的的移动。
- [Apple：Reduced Motion](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/reduced-motion-evaluation-criteria)：为动态敏感用户保留无运动或低运动的等价体验。

这些是设计方向的参考，不是对官方网页的复刻。本项目的品牌使用不构成商标可注册性或名称独占性的保证。
